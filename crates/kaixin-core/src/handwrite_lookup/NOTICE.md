Handwriting matcher notice
==========================

The offline handwriting matcher in this directory is adapted from
`hanzi_lookup` by gugray, a Rust/WebAssembly port of HanziLookup.

Source project: https://github.com/gugray/hanzi_lookup

The matcher source follows the LGPL license terms reproduced in
`LICENSE-LGPL`. The embedded stroke data file `data/mmah.bin` is derived from

`LICENSE-APL`.

updated Rust numeric constant spelling and equivalent lint suggestions for
