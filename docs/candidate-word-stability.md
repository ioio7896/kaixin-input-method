# 候选词跨拼音路径稳定显示

实现入口：`pinyin-ime/src/core/stable_words.rs`。

## 召回与排序

- 全拼（含合法的多种切分）、简拼、混拼及双拼解析后的整词，在昂贵的路径展开前先查询直接索引。每条直接路径保护 16 个系统高频词，并额外保护最多 8 个个人常用词和 8 个上下文相关词；这三组去重后统一排序，路径命中次数不累加分数。全拼和简拼查询已加载的完整精确索引，避免在 16 项截断前漏掉个人常用词。
- 直接命中词和已学读音进入截断保护集合。统一收尾也会补回中间阶段丢失的直接命中词，并过滤屏蔽词、合并重复显示词。
- 部分结果、完整结果和两类缓存结果都调用统一收尾。在相同词长的普通候选位置中，先按匹配可信度，再按系统词频、词语偏好、当前输入习惯、近期使用、上下文和选择反馈的综合分排列。无学习和上下文证据时沿用系统词频；三字词同分保留原顺序，其他词同分按词语固定排序。跨词长歧义保留各自的候选位置，避免只凭词频压掉另一种输入意图。最终不再用纯系统词频覆盖这些证据。
- 明确的二字、三字意图共用首页密度规则；首页至少允许一个可信直接命中词进入普通候选位置。显式置顶、用户实际选词和快捷候选保留独立优先级。
- 词语偏好和当前输入习惯在累计频次至少为 2 时参与统一排序，加分有上限并随学习时钟衰减。全拼、简拼和混拼共享词语偏好，实际选过的输入键有额外加分；生成别名不充当该键的实际选词证据。简拼的个人偏好、当前输入习惯、上下文和选择反馈权重高于全拼，完整全拼仍优先于较弱匹配。每次收尾重建排序分，不向缓存候选分数重复累加。
- 首批尚未完成的组句、纠错等扩展仍可能在完整结果中新增；统一规则保证直接词的处理一致，并不强求不同候选集合的整个列表完全相同。
- 明确且无跨词长切分歧义的完整拼音，在普通候选位置中优先显示精确整词，再显示单字回退、纠错和组句；不改变用户优先或快捷候选的位置。该规则在首批、完整结果和缓存的统一出口执行，不设固定整词配额。
- 当前输入键的额外习惯加分要求至少两次观察及两次实际选择证据（显式置顶除外），避免一次带较大频次增量的学习或同次提交的反馈直接达到门槛。词语共享偏好和上下文仍按既有衰减与上限参与排序。

## 长词与学习

- 混拼索引从二至四字词扩展到精选五至七字词。长词仅限有明确拼音的 Core 词或达到长词词频门槛的 Base 词；每词最多 128 个混拼键。
- 全拼选词仅从实际输入音节生成别名，并要求音节数与词长一致。不再重复调用逐字多音字枚举来学习另一套别名。
- 一次实际混拼选词记录当前读音和词语偏好。由全拼生成的简拼、混拼别名只承担召回和较弱提权，不视为在每条路径上都实际选过一次。
- 最多 127 个生成别名合并为一次持久化事件，不按别名数量增长词语频率或学习时钟。
- 新增别名按输入键清理缓存；实际词语、分词和上下文变化仍沿用原来的定向失效。
- 既有用户词典继续兼容；历史记录中无法区分来源的旧别名不做推断性迁移。

## 候选栏交互

- 沿用同一读音下的交互快照冻结；鼠标左右键按下、TSF 选择和翻页请求都会标记交互，包括重复选择当前第一个候选。
- 未交互的首批在完整结果到达时，保留仍有效候选的显示顺序，移除完整管线过滤掉的临时候选，并把新候选追加到后面；发生交互后沿用严格冻结，保持已选择序号。
- 读音或列表在按下与松开之间发生改变时取消旧按压，避免旧序号提交新词。
- 同一读音、同一页、同一 DPI/布局下，后台补全不收缩候选窗；允许为新增内容扩展尺寸。文本及标签未变时保留候选命中矩形。读音、页码、样式或屏幕条件变化后重新布局。
- 工作线程的输入合并等待以本轮首次等待时刻为基准，后续按键替换待处理请求时不重新开始整个等待周期。性能日志新增 `CandidateWorker/queue-wait`、`CandidateWorker/first-request-to-window` 和 `CandidateWorker/full-request-to-window`，结合已有 lookup 和 request-to-apply 日志定位延迟。这些指标截止于窗口更新调用返回，不代表屏幕实际呈现时间。

## 构建与人工验收

词库 pack schema 为 v13，构建会校验主词库与热词库；冷词库 SQLite schema 为 v2，按必选来源和可选分类保存精确读音回退。旧冷词库版本会安全停用并需重新烘焙。发布门禁使用 `build.py --verify` 执行格式、全目标编译、Rust 单测、评测工具测试、Clippy、严格拼音检查及 x64/x86 原生测试；`--smoke` 另行运行安装包烟测。`build_latest_installers.cmd` 透传参数和构建退出码。

人工验收时，在相应拼音模式开启的情况下，检查：

1. `jisuanji`、`jsj`、`jisj` 的“计算机”召回，以及 `beijing`、`bj`、`beij` 的“北京”召回。
2. 含分隔符、合法多种切分和双拼输入，明确读音不被较弱路径覆盖。
3. 首次输入、重复输入、连续补全、退格重输和缓存命中的直接高频词顺序；无学习记录时仍按系统词频排列。
4. 实际选择后的当前路径提权、其他合法路径的弱提权、上下文相关词前置，以及新别名从旧缓存中及时出现；检查系统词频第 17 项之后的个人常用词能进入保护集合。
5. 首批候选出现后按住鼠标，等待后台补全，再松开；改变拼音后不能误提交旧按压位置的新词。
6. 横竖候选栏、不同页容量、翻页和 DPI 切换下的序号、点击区域及窗口尺寸。

发布门禁通过只能证明自动检查、原生测试和安装包烟测通过；上面的真实 TSF 宿主与候选栏交互仍需在 Windows 文本应用中现场验收，并单独记录结果。
