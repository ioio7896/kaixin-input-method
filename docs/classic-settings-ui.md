# 经典灰蓝设置页

设置程序继续使用 egui / eframe。界面采用中性浅灰背景、白色输入框、钢蓝色选中项、细边框和小直角，布尔设置使用方形复选框。默认以浅色经典主题打开，侧栏仍可切换深色或跟随系统。

## 导航

左侧一级导航包含：输入、皮肤、快捷键、词库、学习词、截图、OCR、剪贴板、翻译、手写、命令与符号、应用兼容、性能日志、系统与维护。

- 皮肤：候选布局、字体与主题、高级标记和皮肤库。
- 词库：扩展词库搜索、启用、导入、数量和来源。
- 学习词：学习策略、用户词条、永远不学列表、自定义短语和快捷码。
- 截图：截图范围、保存与快捷操作。
- OCR：本地识别、结果操作与 OCR 截图保存。
- 剪贴板、翻译、手写和性能日志直接打开对应页面。
- 系统与维护保留通知、隐私与数据、高级调优和版本信息。

搜索结果和 `--section=clipboard` 同步指向新的一级导航。页面恢复推荐只处理当前功能对应的设置。

## 紧凑布局与提示

设置行以 28 个逻辑像素为基准，正文 14，辅助文字 13；侧栏导航项高 30。路径设置使用较宽控件列，常规窗口下目录输入框和浏览按钮保持同行，窄窗口自动换行。

设置详细解释在鼠标停留约 0.35 秒后显示，不在设置行中常驻。标题、行内空白和控件均支持提示；禁用设置仍可查看解释。生效条件完整保留在提示中。敏感应用名单、自定义快捷码、扩展词库用途和来源也提供悬浮说明。运行状态、错误、保存反馈与数据清理提示继续直接显示。

## 验证与产物

设置页测试覆盖窗口尺寸和 DPI、控件与文字重叠、导航宽度、搜索路由、恢复范围、渲染不修改配置，以及启用/禁用设置的悬浮提示。

实际 egui 网格和字体图集可通过现有 `export_hotkeys_layout_preview` 测试导出，在没有交互式桌面的构建环境中生成软件渲染预览。设置 `KX_HOTKEY_LAYOUT_PREVIEW` 指定 JSON 路径；`KX_SETTINGS_PREVIEW_SECTION` 选择导航名称，`KX_SETTINGS_PREVIEW_HEIGHT` 设置画布高度。

本次构建记录、预览和安装包核验清单位于 `dist/classic-settings-ui/`。发布两种安装器：纯输入法，以及输入法 + OCR 集合包。

## 托盘纯游戏模式

托盘右键菜单增加独立勾选项“纯游戏模式（键盘完全直通）”。开启后全局放行按键，包括 Shift、空格、Enter、数字和输入法组合键；取消未完成的输入和候选，不提交残留拼音，并解除截图、剪贴板、设置、OCR、翻译、手写等工具快捷键的全局注册。

该开关优先于全局和应用的中文聊天策略，不能被聊天快捷键重新开启中文。用鼠标在托盘菜单取消勾选后恢复当前应用原有的策略与快捷键，不改写配置文件、原中英偏好或应用规则。正常的游戏规则仍按原配置生效。

开关作为独立用户状态保存在 `HKCU\Software\kaixin\State\PureGameMode`，菜单、图标提示和 TSF 共享该状态；默认关闭。TSF 在测试按键、处理按键、保留键及健康计时器路径中更新状态，覆盖已有宿主和新激活宿主。验证不修改实际用户的注册表开关，不安装或注册输入法。
