# 开心输入法软件 V1.0 软著材料工作区

本目录用于整理“开心输入法软件 V1.0”的计算机软件著作权登记材料草稿。代码和安装包内部使用三段式版本号 `1.0.0`，登记申请表和材料页眉建议统一写作 `V1.0`。

## 材料清单

- `application-info-draft.md`：申请表信息草稿，可用于填报登记系统。
- `user-manual-v1.0.md`：软件说明书/用户手册草稿，可继续补截图并导出 PDF。
- `source-material-plan.md`：源程序鉴别材料的选取范围、排除范围和生成建议。
- `third-party-components.md`：第三方组件、外部数据和待核验许可清单。

## 提交前待确认

- 申请人主体：个人身份证或公司营业执照信息。
- 开发完成日期：建议填写 V1.0 冻结当天或实际完成当天。
- 首次发表状态：未发表，或填写首次公开发布的具体日期、地点、方式。
- 权属说明：确认是否独立开发；如有合作、委托、职务开发，需要相应证明。
- 文档页眉：软件名称、版本号、页码和申请表保持一致。
- 源程序材料：只放自研核心代码，避免把第三方 OCR 源码、模型、词库当作自研源程序提交。
- 第三方组件：发布安装包前核验 RapidOCR、ONNX/OCR 模型、wordfreq 英文词频、手写查字数据等许可；WinTranslator 作为独立软件管理自身依赖。
