# 开心输入法软件 V2.0 用户手册

## 1. 软件概述

开心输入法软件 V2.0 是一款运行于 Windows 桌面系统的本地拼音输入法。软件通过 Windows TSF 文本服务框架接入系统输入法列表，用户可在 Windows 输入法切换面板中选择“开心输入法”进行中文输入。

软件提供拼音输入、候选词选择、用户词库学习、剪贴板管理、手写查字、截图 OCR、离线翻译、候选窗皮肤和隐私数据管理等功能。软件的设计重点是本地、干净、可控，输入内容、用户词库、剪贴板历史和 OCR 历史默认保存在用户本机。

## 2. 运行环境

硬件环境：x86 或 x64 架构个人计算机，键盘、鼠标和显示器。

软件环境：Windows 10 或 Windows 11，系统需支持 Windows TSF 文本服务框架。OCR 和翻译功能需要安装包中包含相应本地运行时和模型文件。

## 3. 安装与启动

用户运行安装包后，安装程序会将开心输入法注册到 Windows 文本服务，并创建开始菜单入口。安装完成后，用户可通过 Windows 输入法切换面板选择“开心输入法”。

开始菜单通常包含以下入口：

- 开心输入法设置
- 开心输入法剪贴板
- 开心输入法手写查字
- 开心输入法 OCR
- 开心输入法中英翻译
- 卸载开心输入法

如果安装后输入法没有立即出现在输入法切换列表中，可尝试注销并重新登录系统，或在 Windows 语言设置中检查“中文（简体，中国）”下的键盘列表。

## 4. 基本输入

用户在文本框中切换到开心输入法后，直接输入拼音即可显示候选窗口。输入法支持全拼、简拼、混拼和整句输入。用户可使用数字键选择候选，也可按空格或回车提交首选候选。

默认按键如下：

| 操作 | 默认按键 |
| --- | --- |
| 输入拼音 | a-z |
| 选择候选 | 1-9 |
| 提交首选候选 | Space / Enter |
| 取消输入 | Esc |
| 删除拼音 | Backspace |
| 候选翻页 | - / =、, / .、PageUp / PageDown |
| 中英文临时切换 | Shift |
| 截图 OCR | Ctrl+Shift+Alt+A |
| 打开剪贴板 | Ctrl+Shift+Alt+V |

## 5. 候选窗口

候选窗口用于显示当前拼音对应的候选字词、序号和辅助提示。用户可通过键盘或鼠标选择候选。候选窗口支持横排和竖排显示，支持每页候选数、字体、字号、透明度、颜色模式、布局密度、皮肤主题等设置。

候选窗口会根据当前输入焦点和文本光标位置定位。在全屏应用或特殊窗口中，用户可通过设置页配置候选栏显示策略、英文模式和提交方式 fallback。

## 6. 拼音能力

软件支持以下输入能力：

- 全拼：输入完整拼音得到候选。
- 简拼：输入声母组合快速得到长词候选。
- 混拼：允许部分音节完整输入、部分音节使用声母。
- 整句输入：连续输入较长拼音时生成整句候选。
- 单字候选：词库没有完整词时仍可逐字上屏。
- 智能纠错：对邻键误触、漏键等常见输入错误进行候选补偿。
- 模糊音：支持 z/zh、c/ch、s/sh、n/l、f/h、an/ang、en/eng、in/ing 等配置。
- 双拼：支持内置双拼方案，可在设置页启用。

## 7. 用户词库与学习

软件会根据用户上屏行为记录词条、频次和上下文信号，用于优化后续候选排序。用户词库保存在本地数据目录中，并在 Windows 上默认使用 DPAPI 进行保护。

设置页提供以下用户词库操作：

- 导入用户词库
- 导出明文用户词库
- 解密导出
- 添加自定义短语
- 清空用户词库
- 启用或禁用扩展词库

自定义短语可用于快速输入常用文本。例如设置 `;qq = name@example.com` 后，输入 `;qq` 或 `vv ;qq` 即可调出该文本候选。

## 8. VV 直输助手

用户输入 `vv` 加命令可直接得到常用文本候选。常用命令包括：

| 命令 | 用途 |
| --- | --- |
| vv rq / vv date | 日期 |
| vv sj / vv time | 时间 |
| vv xq / vv week | 星期 |
| vv sym / vv fh | 符号 |
| vv emoji | Emoji 表情 |
| vv unit / vv dw | 单位 |
| vv dx / vv rmb / vv money | 金额大写 |
| vv mail / vv email | 邮箱片段 |
| vv url / vv site | 网址片段 |
| vv md / vv markdown | Markdown 片段 |
| vv cb / vv clip | 剪贴板候选 |
| vv hw / vv handwrite | 手写查字 |

## 9. 剪贴板管理

剪贴板管理器用于本地保存文本剪贴板历史。后台记录默认关闭，用户可在设置页中开启。开启后，软件可保存普通记录和置顶记录，并支持搜索、置顶、复制、粘贴、清空和快粘。

剪贴板历史只保存在本机，不上传到网络服务。用户可在“隐私与数据”设置中清空剪贴板历史或打开本地数据目录。

## 10. 手写查字

手写查字窗口提供手写画布和识别候选列表。用户可在画布中书写汉字，软件显示相近候选。用户可复制候选文字，也可直接粘贴到当前目标窗口。该功能适合遇到不确定读音的汉字时快速查找。

## 11. 截图 OCR

OCR 工具用于识别屏幕区域中的文字。用户可通过托盘入口或快捷键打开 OCR 工具，选择屏幕区域后，软件调用本地 OCR 运行时识别文字。

OCR 功能集成第三方开源项目 RapidOCR 及相关本地 OCR 模型。开心输入法自研部分包括截图交互、窗口界面、参数配置、结果处理、历史记录、剪贴板联动、输入法集成、安装部署和隐私数据管理；不主张 RapidOCR 工程源码、OCR 模型及 Python 运行时依赖的著作权。

OCR 工具支持：

- 屏幕区域截图
- 目标窗口截图
- 中文、英文、中英混合识别
- 增强对比度、黑白化、放大、去噪和反色识别
- 二次框选
- 去空格、去换行、保留段落和表格模式
- OCR 历史
- 复制、粘贴和加入剪贴板历史

## 12. 中英翻译

“输入法 + OCR + 外部翻译联动”安装包不携带翻译运行时或模型。用户可从托盘、设置页或 OCR 结果把文本通过当前用户命名管道发送给另行安装的 WinTranslator，并由 WinTranslator 自动翻译。

如果 WinTranslator 未安装，软件会显示安装或路径配置提示，并保持输入法核心与 OCR 功能可用。

## 13. 外观设置

用户可在设置页调整候选窗口外观，包括每页候选数、横排/竖排、经典/紧凑/卡片布局、密度、字号、透明度、字体、浅色/深色/跟随系统、高对比度和主题皮肤。

软件内置多套主题文件，位于 `skins/` 目录。新增皮肤可参考现有主题文件格式。

## 14. 隐私与数据

软件不上传输入内容、候选、截图、剪贴板或用户词库。主要本地数据路径如下：

| 数据 | 位置 |
| --- | --- |
| 本地数据目录 | `%LOCALAPPDATA%\kaixin` |
| 配置文件 | `%LOCALAPPDATA%\kaixin\kaixin.ini` |
| 日志目录 | `%LOCALAPPDATA%\kaixin\logs` |
| 用户词库 | `%LOCALAPPDATA%\kaixin\user_dict.sqlite` |
| 剪贴板历史 | `%LOCALAPPDATA%\kaixin\clipboard_store.sqlite` |
| OCR 历史 | `%LOCALAPPDATA%\kaixin\ocr_history.sqlite` |

设置页提供打开本地数据目录、备份配置、恢复配置、导出隐私说明、清空用户词库、清空剪贴板历史、清空日志和导出诊断包等操作。

## 15. 卸载

用户可通过开始菜单卸载入口或 Windows 应用管理界面卸载开心输入法。常规卸载默认保留用户配置和用户数据。需要清理用户数据时，可在设置页中先清空用户词库、剪贴板历史和日志，或使用安装器提供的数据清理参数。

## 16. 常见问题

输入法没有出现在系统列表中：检查是否完成安装和注册，必要时注销后重新登录。

候选窗口不显示：检查当前应用是否处于全屏兼容模式，或在设置页调整候选窗口策略。

OCR 不可用：检查安装目录中是否包含 OCR 运行时、RapidOCR 目录、Python 运行时和模型文件。

翻译不可用：检查是否已安装 WinTranslator；默认路径为 `%LOCALAPPDATA%\Programs\WinTranslator\WinTranslator.exe`，也可通过 `WINTRANSLATOR_EXE` 指定。

候选不符合习惯：可继续使用让软件学习，也可清空用户词库、调整扩展词库和模糊音设置。
