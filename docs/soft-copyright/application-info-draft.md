## 软件功能简介

开心输入法软件是一款面向 Windows 桌面环境的本地中文拼音输入法。软件通过 Windows TSF 文本服务框架接入系统输入法列表，提供全拼、简拼、混拼、整句输入、候选排序、用户词库学习、候选窗皮肤、剪贴板管理、手写查字、截图 OCR、离线翻译和隐私数据管理等功能。

软件以本地处理为核心设计目标，候选计算、词库学习、剪贴板历史、截图 OCR 历史和配置数据均保存在用户本机。软件默认不依赖云端服务，不上传输入内容、截图、剪贴板或用户词库。

## 主要功能模块

1. 拼音输入模块：支持全拼、简拼、混拼、整句候选、单字候选、英文候选、模糊音、双拼和常见输入纠错。
2. 候选排序模块：结合内置词库、用户词库、上下文学习、词频和 Bigram 语言模型生成候选列表。
3. TSF 前端模块：基于 C++/Win32 实现输入法注册、文本服务接入、候选窗口显示、键盘事件处理和上屏提交。
4. 设置管理模块：提供中英文切换、全半角、中文标点、模糊音、双拼、翻页键、热键、候选窗口样式、隐私数据等配置。
5. 用户词库模块：记录上屏词、频次和上下文信号，支持导入、导出、添加自定义短语和清空用户词库。
6. VV 直输助手：支持日期、时间、星期、符号、表情、单位、金额大写、邮箱片段、网址片段、Markdown 片段和剪贴板候选。
7. 剪贴板管理模块：本地保存文本剪贴板历史，支持搜索、置顶、复制、粘贴、清空和快粘。
8. 手写查字模块：提供手写画布和候选列表，可复制或直接粘贴识别出的汉字。
9. OCR 模块：通过本地 OCR 运行时识别屏幕区域文字，支持图像增强、二次框选、结果清理和历史记录。
10. 翻译联动：通过当前用户命名管道把文本交给独立安装的 WinTranslator。
11. 安装卸载模块：提供机器级/用户级安装、输入法注册、开始菜单入口、卸载和可选数据清理。

## 技术特点

- 使用 Rust 实现核心拼音引擎、用户词库、设置页、托盘工具、剪贴板、手写查字、OCR/翻译窗口等模块。
- 使用 C++/Win32 接入 Windows TSF 文本服务框架，实现候选窗口绘制、输入上下文处理和上屏提交。
- 采用 SQLite 保存用户词库、剪贴板历史和 OCR 历史，并在 Windows 上使用 DPAPI 保护敏感本地数据。
- 候选窗口支持横排/竖排、经典/紧凑/卡片布局、浅色/深色/高对比度、透明度、字体和主题文件。
- OCR 使用本地运行时和本地模型；翻译文本通过当前用户命名管道发送给独立安装的 WinTranslator。
- 构建脚本支持 IME、IME+OCR、IME+OCR+外部翻译联动多种安装包变体。

## 权属边界说明

申请材料中的自研软件成果主要包括拼音输入引擎、候选排序与学习逻辑、TSF 输入法前端、候选窗口、设置页、托盘工具、剪贴板管理、手写查字集成、OCR/外部翻译请求集成、安装器脚本和隐私数据管理逻辑。

第三方 OCR 源码、Python 运行时依赖、OCR 模型、外部词库、英文词库、手写数据和平台 API 不作为本软件自研源程序主张。相关组件详见 `third-party-components.md`。

本软件的 OCR 和外部翻译联动为本地辅助功能。申请人自研部分包括截图交互、参数配置、结果处理、历史记录、剪贴板联动、命名管道请求、安装部署和隐私数据管理等逻辑。OCR 引擎和 OCR 模型不作为申请人独立开发的源程序主张权利。

OCR 功能集成第三方开源项目 RapidOCR 及相关本地 OCR 模型。申请人不主张 RapidOCR 工程源码、OCR 模型及 Python 运行时依赖的著作权。

输入法不包含翻译运行时或模型，仅实现与独立 WinTranslator 的本地请求协议和 OCR 文本联动。
