# TSF 宿主回归

本次改动涉及 `text_edit_sink.cpp`、`composition_sink.cpp`、`thread_mgr_sink.cpp`、
`key_sink.cpp` 及组合串提交／生命周期代码。文本编辑回调只使用只读锁检查；
删除预编辑和结束组合串通过异步读写编辑会话完成。清理持有原组合串对象，
不会把新焦点作为提交目标。宿主拒绝清理时记录诊断，不重发已经写入的文字。

自动回归见 `tsf-tip/tests/policy_tests.cpp` 的 `TestTsfHostFailureSequences`：
覆盖写入成功但结束失败、写入被拒绝、部分写入、同步终止重入、回调重复执行、
旧会话异步回调失效，以及光标／选择范围的边界和比较失败。

安装后在记事本、Word、浏览器 textarea／contenteditable、Electron 编辑框分别检查：

| 操作 | 预期 |
| --- | --- |
| 输入 `nihao`，点击同一输入框内组合串外的位置 | 旧候选消失，随后输入从新光标位置开始 |
| 将光标移到组合串内部或边界 | 保留当前组合串 |
| 拖动选择范围覆盖组合串之外的文字 | 结束旧会话，不删除宿主替换的文字 |
| 输入期间滚动编辑区 | 候选跟随组合串位置，不保留旧锚点 |
| 宿主脚本替换组合串文字或主动终止组合串 | 保留宿主文字，旧候选和旧任务失效 |
| 输入框 A 输入拼音后切到 B，再迅速切回 A | 不向 B 提交 A 的文字，旧清理不删除 A 的新组合串 |
| 输入期间 Alt+Tab、关闭弹窗或标签页 | 旧查询不能重新显示候选，新输入可正常开始 |
| 长按退格、快速连续按空格 | 每次实际按键最多处理一次，无重复上屏 |
| Shift 配合快捷键；按住 Shift 切换焦点后松开 | 快捷键正常，松键不误触发中英文切换 |

真实应用验收需安装后人工执行；策略测试不能替代宿主提供的 TSF 回调和布局行为。
