# 紧凑工具风格设置页

保留现有 egui / eframe 前端、配置格式和原生输入法功能。此次调整设置页布局，不修改候选引擎、全屏游戏策略或配置默认值。

## 页面与布局

- 侧栏由 212 缩至 184 个逻辑像素，导航项由 42 缩至 34；状态摘要移到悬停说明，避免与中文标题重叠。
- 设置正文字号 14，说明字号 13；设置行最低高度 28，垂直内边距 2，使用细边框、小圆角分组。
- 搜索移至页面顶部，可直接跳转到外观、词库、工具和系统的对应分页。切换分页时回到页面顶部。
- 外观分为“布局与显示 / 字体与主题 / 高级标记”。保留全部原有设置项、快捷外观方案和皮肤库。皮肤库、快捷方案默认折叠。
- 候选预览放在页内，预览画布最大高度 160；保留滚动查看完整候选内容及“保存并用真实候选窗试用”入口。
- 词库分为“学习策略 / 用户词条 / 扩展词库”。保留屏蔽词、自定义快捷码、词库搜索、来源、统计、分组批量操作和导入。扩展列表为空时仍可导入或重新加载。
- 诊断使用条纹状态表，延迟表在窄窗口中可横向滚动；保留日志级别、清理与导出和事件详情。
- 高级调优直接展开排序和缓存参数。内容宽度达到 900 时，外观及高级分组使用双列；更窄时自动使用单列。
- 保留浅色 / 深色 / 跟随系统主题、未保存提醒、放弃修改、恢复推荐和保存行为。

## 验证范围

执行 Rust 编译及设置页自动化检查。布局检查使用内存中的 egui Context，覆盖窄窗口、双列临界宽度、100% / 150% / 200% DPI、长说明、诊断事件、导航标题、分页搜索、保存按钮稳定位置以及渲染不修改设置。

按用户要求，不启动桌面设置程序、真实候选窗或游戏进行实测，不安装或注册输入法。打包禁用运行时 smoke 与 verify，交付后使用包清单、组件哈希及 PE 架构进行静态核验。

交付检查记录位于 `dist/compact-settings-ui/validation.json`，完整打包日志位于 `dist/compact-settings-ui/installer-build.log`。
