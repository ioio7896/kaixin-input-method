# 游戏输入栏中文唤起优化

2026-10-09。本次实现未安装输入法、未进入游戏、未执行真实游戏或桌面宿主实测。
构建、单元测试、配置往返和安装包静态校验与游戏兼容验证分别记录。

## 已实现的行为

- 默认游戏键盘直通；手动中文聊天仍是未知输入栏的兜底。`auto_text` 扩展为原生编辑框、具有明确文本输入范围和可信布局的 TSF 编辑区，以及提供可写 Edit/ValuePattern 的 UI Automation 输入栏。
- 自动识别检查实际焦点上下文、窗口归属、可见/启用、只读和密码状态。可写的默认 TSF 上下文本身不会启用中文。
- UI Automation 在后台 MTA 工作线程运行，设置连接/事务超时。按键路径只读取缓存、排入请求，不读取输入正文；核对运行时元素身份，并拒绝超过 350 ms 的证据。线程闲置后退出并持有模块引用，避免 DLL 提前卸载。
- 聊天分为直通、等待确认、编辑、提交中。按游戏配置的开启键仍交给游戏；等待最多 1.2 秒，未确认时继续直通。发送后保留输入栏的游戏可设置 `stay`；`auto` 在已确认编辑栏内保留中文，在未知手动会话内退出。
- 有拼音时 Enter 选词、Esc 取消拼音；没有拼音时，关闭键交给游戏并结束中文。重复的选词 Enter/Esc 不会在拼音结束后变成游戏发送/关闭键。
- 真实按键 trace 通知负责状态切换和物理按键归属。测试回调不执行聊天退出或改变按键归属。游戏收到的移动键一直归游戏所有，直到松开；Alt+Tab 后未知的长按重复也保持直通。手动切换热键使用松键重新武装，防止长按连续切换。
- 异步按键编辑未执行时，Enter/Esc 不提前结束会话。等待超过 1 秒时取消游戏会话并放行；旧回调通过会话代次校验失效。
- 尊重 `BeginUIElement` 的 `pbShow=FALSE` 和 `Show(FALSE)`，向宿主继续提供候选更新。外部渲染后端与强制显示是两个独立选项；只有每游戏的 `overlay_force_ui=1` 才覆盖宿主隐藏要求。
- 自动位置先采用可信 TSF/光标/输入栏几何，随后回退现有安全游戏位置。保留固定位置、逻辑像素偏移、缩放和目标显示器设置，UIA 的物理坐标转换后使用。
- 聊天开启显示短暂无焦点提示，开始输入后隐藏提示，并在候选中显示“中文聊天”。UI-less 宿主不显示独立通知。
- 提交前检查窗口、PID、原生焦点、会话和修饰键。给 Unicode/粘贴事件加标记，防止重新进入拼音。明确配置的提交方式不会静默换另一种方式重发。
- 日志区分 TSF `written` 与注入 `sent_unconfirmed`；部分发送、焦点取消、目标终止禁止自动重试。明确失败保留可继续编辑的拼音；部分发送停止整段重试。
- 剪贴板恢复移到原 STA 的定时回调，只有本次剪贴板序号仍有效才恢复，用户新复制内容不会被覆盖。恢复期间不开始另一笔粘贴；取消按键线程固定休眠和剪贴板锁重试等待。
- 共享 Unity/SDL/GLFW 等窗口类不再单独将工具或编辑器分类为游戏；明确应用配置和进程规则仍然生效。

## 配置与兼容向导

设置页提供全局/按游戏的空 Enter 行为、后台辅助识别、状态提示，按游戏的开启键、关闭键和强制候选选项。
向导按准备、按键接入、候选显示、位置、上屏、退出恢复进行，每一项由玩家确认。
显示模式由玩家选择，不用窗口尺寸推断独占全屏；游戏版本可手动填写。
新配置的确认记录均为 false，构建和自动化测试不写入游戏验证结果。
修改显示模式/版本、聊天行为或提交/渲染方式，会清除相应确认结果。
详细配置见 [配置参考](config_reference.md)。

## 自动检查与实际能力边界

原生策略测试覆盖长按归属、废弃/重复测试回调、焦点恢复、选词 Enter 长按、UI-less 协商、证据过期、提交状态和取消后禁止重试。
原生配置测试覆盖新字段解析；Rust 设置测试覆盖配置保存/重载、默认未验证记录和结果清除，并保留已有设置布局测试。
构建需要 x64/x86 TIP 和覆盖层，输出纯输入法与输入法＋OCR 两个安装器；安装包清单与组件架构另行静态校验。

没有提供输入上下文、可编辑接口、Unicode 或粘贴能力的自绘输入栏，不能靠覆盖层自动解决按键接入和文字提交。
UIA 多行编辑区未提供 ValuePattern、默认输入范围的 TSF 自绘区，继续使用手动模式；本次没有增加图形注入或游戏进程补丁。
独占全屏可能阻挡普通窗口覆盖层，需要宿主自行绘制候选或选择无边框模式。本次不宣称任何具体游戏通过了兼容实测。
后台检测有缓存窗口；外部提交受 Windows 权限及游戏对输入事件的处理方式影响，事件发送成功不等于游戏上屏成功。
剪贴板恢复延迟是有界兼容策略，无法证明所有游戏已完成异步读取；相关时序仍需未来按游戏确认。
